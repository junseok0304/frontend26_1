## vue 프로젝트

특징 1.
확장된 js 문법으로 구현한다.
웹브라우저가 이해할 수 없기 때문에 표준 js 문법으로 변환해야 웹브라우저에서 실행될 수 있다. 이 작업을 트랜스파일 이라고 한다.

특징 2. 
vue 프로젝트는 실행 전 소스코드를 트랜스파일 해야 한다. 
*.vue -> *.js 
소스코드 -> 기계어, 바이트코드 = 컴파일 
소스코드 -> 다른 문법의 소스코드 = 트랜스파일 

특징 3. 
압축한다. minify라고 하며, 
줄인 js파일의 이름은 *.min.js 형태인 것이 관례이다.
이렇게 생성한 *.min.js 파일이 웹 브라우저에서 실행된다.

## npm 패키지
프로젝트 개발에 필요한 라이브러리를 다운로드 할 수 있는 명령이다.
프로젝트의 node_modules 디렉토리에 라이브러리들이 설치된다.
js 라이브러리를 npm 패키지 라고 부른다.

## 번들 
라이브러리 파일들을 포함하면 프로젝트에 무수히 많은 파일들이 있다.
프로젝트를 빌드해 실행파일을 만들 때, 프로젝트의 많은 파일들이 결합되어 파일 3-4개의 실행파일이 생성된다. (*.min.js 파일)

## 프로젝트를 빌드 해야한다. 
빌드 = 트랜스파일 + 미니파이(압축) + 번들 
빌드 결과 생성된 *.min.js 파일을 빌드파일, 배포파일 이라고 부른다. 

vue 프로젝트의 빌드파일이 웹브라우저에서 실행된다.
